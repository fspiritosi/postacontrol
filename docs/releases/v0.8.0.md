Tareas locales con aviso en el escritorio y conexión con Taskapp: crear una tarea o un ticket desde un correo, sumar las respuestas del hilo y ver tus pendientes.

## Novedades

- **Tareas locales:** una vista «Tareas» para crear, editar y marcar tareas con fecha y hora, agrupadas por vencimiento. Viven solo en esta PC.
- **Avisos:** notificación del escritorio antes del vencimiento, con la anticipación que elijas («A la hora» incluida). Llega aunque la ventana esté cerrada en la bandeja, y al hacer clic se abre la tarea.
- **Crear en Taskapp desde un correo:** una tarea o un ticket con el `.eml` adjunto. El proyecto se sugiere según el remitente; nunca se deduce de un dominio público (gmail, hotmail, etc.). Se puede cancelar sin crear nada.
- **Sumar a la tarea:** las respuestas posteriores del hilo se suman como comentarios internos de la tarea.
- **Pendientes de Taskapp:** tus tareas pendientes de Taskapp aparecen en la vista «Tareas», solo para ver.
- **Conectar Taskapp:** en Configuración, por el navegador, con el mismo flujo que la CLI de Taskapp.
- **Respaldo:** las tareas locales van incluidas en el respaldo de Configuración → Respaldo.
- **Atajo:** `t` crea una tarea desde el correo abierto.

## Instalación

**Ubuntu 24.04+ / Debian 13+**

```sh
sudo apt install ./postacontrol_0.8.0_amd64.deb
```

**Fedora 42+**

```sh
sudo dnf install ./postacontrol-0.8.0-1.x86_64.rpm
```

Si ya tenés una versión anterior, el mismo comando la actualiza. Tus cuentas y tu correo se conservan. Esta versión actualiza la base de datos local (v17); una versión anterior ya no puede abrirla.

Después de instalar, salí de la app desde el ícono de la bandeja (Salir) y volvé a abrirla.

## Verificar la descarga

```sh
sha256sum -c SHA256SUMS
```
