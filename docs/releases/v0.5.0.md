Respaldo de tus datos, archivar y atajos de teclado, deshacer (también el envío) e imágenes permitidas por remitente.

## Novedades

- **Respaldo:** en Configuración → Respaldo podés exportar a un archivo tus contactos, firmas, etiquetas y reglas, que viven solo en esta PC, e importarlos en otra. Importar suma lo que falta y no pisa ni borra nada. El correo no va en el respaldo (está en el servidor), y las contraseñas tampoco.
- **Archivar:** un botón en el correo abierto y en la barra de selección, y la tecla `e`. Si la cuenta no tiene carpeta Archivo, se crea.
- **Atajos de teclado:**
  - `j` / `k` para moverse;
  - `r`, `a` y `f` para responder, responder a todos y reenviar;
  - `Supr` para la Papelera;
  - `s` para destacar y `u` para marcar como no leído;
  - `n` para redactar y `/` para buscar.

  Con `?` se ve la lista completa.
- **Deshacer:** después de mover, archivar o mandar a la Papelera, el aviso ofrece «Deshacer». La tecla `z` deshace lo último.
- **Deshacer envío:** el correo espera 10 segundos antes de salir y el aviso «Enviando correo…» deja arrepentirse. Si lo deshacés, queda en la Bandeja de salida y se abre para seguir editándolo. Si cerrás la app antes, el correo sale igual. Se apaga en Configuración → Redacción.
- **Imágenes remotas por remitente:** junto a «Mostrar imágenes», «Siempre de este remitente». La lista se edita en Configuración → Lectura.

## Instalación

**Ubuntu 24.04+ / Debian 13+**

```sh
sudo apt install ./postacontrol_0.5.0_amd64.deb
```

**Fedora 42+**

```sh
sudo dnf install ./postacontrol-0.5.0-1.x86_64.rpm
```

Si ya tenés una versión anterior, el mismo comando la actualiza. Tus cuentas y tu correo se conservan. Esta versión actualiza la base de datos de la app: después de instalarla, una versión anterior ya no la puede abrir.

Después de instalar, salí de la app desde el ícono de la bandeja (Salir) y volvé a abrirla.

## Verificar la descarga

```sh
sha256sum -c SHA256SUMS
```
