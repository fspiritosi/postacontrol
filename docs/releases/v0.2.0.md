Configuración por secciones y Reglas para ordenar el correo solo.

## Novedades

- **Reglas:** mueven, marcan como leído, destacan, etiquetan o mandan a la Papelera el correo nuevo que llega a la Entrada, según quién lo manda, a quién va o el asunto. Son como los filtros de Thunderbird: cada cuenta tiene su lista y se aplican en orden.
- **«Crear regla…»:** desde un correo (en el lector o con clic derecho) se crea una regla para su remitente en dos clics.
- **«Aplicar ahora»:** pasa las reglas por todo lo que ya hay en una carpeta.
- **Configuración ordenada:** una barra lateral con General, Lectura, Redacción, Cuentas, Etiquetas y Reglas, en vez de todo junto.

## Instalación

**Ubuntu 24.04+ / Debian 13+**

```sh
sudo apt install ./postacontrol_0.2.0_amd64.deb
```

**Fedora 42+**

```sh
sudo dnf install ./postacontrol-0.2.0-1.x86_64.rpm
```

Si ya tenés la 0.1.0, el mismo comando la actualiza. Tus cuentas y tu correo se conservan.

## Verificar la descarga

```sh
sha256sum -c SHA256SUMS
```
