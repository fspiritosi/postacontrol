Vaciar la Papelera de una vez, arrastrar destinatarios entre Para, CC y CCO, y ver la contraseña al escribirla.

## Novedades

- **Vaciar Papelera:** un botón en la cabecera de la Papelera (o clic derecho sobre la Papelera en la barra lateral → «Vaciar Papelera…») borra todos sus correos de una sola vez, también los que todavía no se bajaron. Pide confirmación y avisa cuántos se borran.
- **Arrastrar destinatarios:** un chip de Para, CC o CCO se arrastra a otro de esos campos. Si CC/CCO estaban ocultos, se despliegan al empezar a arrastrar, y si la dirección ya está en el destino no se repite.
- **Ver la contraseña:** los campos de contraseña (alta de cuenta, edición y «Cambiar contraseña») tienen un ojo para mostrar u ocultar lo escrito.
- **Instalación:** `task install:desktop` ya no tapa el paquete instalado con una copia en `~/.local/bin`.

## Instalación

**Ubuntu 24.04+ / Debian 13+**

```sh
sudo apt install ./postacontrol_0.4.0_amd64.deb
```

**Fedora 42+**

```sh
sudo dnf install ./postacontrol-0.4.0-1.x86_64.rpm
```

Si ya tenés una versión anterior, el mismo comando la actualiza. Tus cuentas y tu correo se conservan.

## Verificar la descarga

```sh
sha256sum -c SHA256SUMS
```
