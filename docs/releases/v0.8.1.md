Corrección del formulario de tareas.

## Correcciones

- **Crear tarea:** el formulario ya no se sale de la ventana con correos de HTML largo. Queda dentro de la pantalla y, si hace falta, se desplaza por dentro. Lo mismo para el editor de tareas locales.

## Instalación

**Ubuntu 24.04+ / Debian 13+**

```sh
sudo apt install ./postacontrol_0.8.1_amd64.deb
```

**Fedora 42+**

```sh
sudo dnf install ./postacontrol-0.8.1-1.x86_64.rpm
```

Si ya tenés una versión anterior, el mismo comando la actualiza. Tus cuentas y tu correo se conservan. Si venís de la 0.7 o anterior, esta versión actualiza la base de datos local (v17) y una versión anterior ya no puede abrirla.

Después de instalar, salí de la app desde el ícono de la bandeja (Salir) y volvé a abrirla.

## Verificar la descarga

```sh
sha256sum -c SHA256SUMS
```
